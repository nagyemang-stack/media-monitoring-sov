# Competitive Media Monitoring & Share-of-Voice

> A competitive intelligence tool for tracking brand mentions, calculating share-of-voice, and identifying sentiment shifts across the media landscape.

**Author:** Caleb Agyemang
**Role:** PR & Data Analytics Professional
**Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn

---

## Overview

This project builds a media monitoring system that continuously tracks brand mentions across news outlets, social platforms, and industry publications. The tool calculates share-of-voice (SOV) against competitors, applies natural language processing to score sentiment, and identifies emerging trends in real-time.

Share-of-voice is calculated as a brand's mention volume divided by total industry mentions. Combined with sentiment scoring and source attribution, this produces a comprehensive competitive landscape view that PR teams can use to adjust messaging strategy.

## Methodology

**Share-of-Voice Calculation:**

```
SOV = (Brand Mentions / Total Industry Mentions) × 100
```

This standard PR metric shows a brand's visibility relative to its competitive set. A SOV above 30% typically indicates market leadership in media presence.

**Sentiment Scoring:** Net sentiment is calculated as:

```
Net Score = (Positive Mentions − Negative Mentions) / Total Mentions × 100
```

Scores range from -100 (entirely negative) to +100 (entirely positive). Positive net scores above +30 indicate strong brand health.

**Competitor Alerts:** The system flags competitors with SOV changes exceeding ±3 percentage points week-over-week, enabling rapid strategic response.

**Source Attribution:** Mentions are categorized by media type (tech blogs, industry news, social media, trade publications, forums, video platforms) to identify which channels drive the most brand conversation.
